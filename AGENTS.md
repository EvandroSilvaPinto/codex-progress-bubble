# Manutenção do Progress Bubble

- Atualizar o `README.md` sempre que alterar o projeto, na mesma entrega. Documentar o comportamento final, comandos e limitações relevantes. Para mudanças internas sem efeito no uso, registrar a informação na seção de desenvolvimento sem inventar novidades.
- Manter exemplos, nomes da skill e caminhos consistentes com a implementação.
- Atualizar a demonstração animada quando uma mudança visual tornar o GIF enganoso.
- Executar os testes relevantes antes de concluir. Não publicar mudanças sem autorização do usuário.
